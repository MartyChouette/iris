Overview

Redesign the date scoring presentation so each phase has a deliberate, player-felt reveal of points, multipliers, and flower growth. Phase 1 judgments play one-at-a-time with flower feedback per beat. Phase 2 makes the drink tasting a dramatic centerpiece moment. Phase 3 switches from automatic room scanning to player-driven item clicking. All phases end with a "Continue" button so the player controls pacing.

Player Fantasy

Every judgment feels like a mini-verdict — the flower is the emotional barometer you're watching while the date reacts. You feel the tension of each reveal, the satisfaction of a good pick, and the dread of a bad one. In Phase 3, you're a curator showing off your apartment, choosing what to highlight and in what order.

Phase 1 — Impressions (Sequential Reveal)

Current Behavior exists

EntranceJudgmentSequence.RunJudgments() evaluates music, perfume, outfit, and cleanliness one-at-a-time with 3.2s gaps. Each fires ApplyReaction() which updates the flower via OnAffectionChanged.

Changes modify

  1. Flower beat per judgment — After each reaction bubble, hold ~0.8s so the player watches the flower pulse (Like) or wilt (Dislike). Add a UI flash on the flower area to direct attention.
  2. Multiplier popups on flower — AffectionBar.ShowPopup() already fires per judgment. Add the multiplier suffix when applicable (e.g. "Your Music ♥ ×2"). ShowJudgmentJuice() needs the multiplier from GetTagEffectMultiplier.
  3. No auto-advance — After all 4 judgments, show "Continue" button instead of immediately starting Phase 2.

Unchanged

Judgment order (music → perfume → outfit → cleanliness), evaluation logic, personality pre-comments, SFX, reaction particles.

Phase 2 — Drinks (Big Moment)

Current Behavior exists

ReceiveDrink(recipe, score) calls ApplyReaction() once and immediately starts the Phase 3 transition.

Changes modify

  1. Tasting beat — After delivery, insert a dramatic sequence:
    Pick up drink ~0.5s
    Suspenseful sip / thinking face ~1.5s
    Verdict reaction Big bubble + particles + SFX
    Flower + popup Score contribution shown, multiplier if applicable
  2. Score granularity (optional) — Show raw score as flavor text on popup (e.g. "Great mix! +8 ♥"). Tuning knob — can revert to simple reaction.
  3. No auto-advance — Show "Continue" button after drink verdict.

Unchanged

DrinkPourManager flow, ReactionEvaluator.EvaluateDrink() logic, pour mechanics, bottle handling.

Phase 3 — Warming Up (Player-Driven)

Current Behavior exists

RevealAllReactions() auto-scans all active ReactableTags, sorts by multiplier, plays them as a wave with 0.6s stagger. Player is passive.

Changes new mechanic

  1. Player clicks items — Use the existing DateInspectSystem. Each click on a ReactableTag item:
    • Wiggle animation exists
    • Labeled reaction bubble + icon exists
    • Points + multiplier popup on flower exists
    • World-space multiplier popup new
    • Flower grows/shrinks exists
  2. Multiplier popup on inspect — TryInspect() currently does NOT spawn SpawnMultiplierPopup(). Add it when multiplier > 1.
  3. "Continue" button visible from start — Player clicks when done exploring.
  4. Remaining items sweep — On "Continue", un-inspected active ReactableTags get the existing wave treatment (particles, highlights, multiplier popups, 0.6s stagger).
  5. Disable auto-scan — RevealAllReactions() only runs for un-inspected remainder.

Unchanged

ReactableTag system, DateInspectSystem hover tooltips, ReactionEvaluator logic, multiplier calculation, highlight system.
